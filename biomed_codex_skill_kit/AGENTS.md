# Biomedical manuscript project instructions

For manuscript drafting, translation, evidence-boundary audits, statistical/figure checks, or pre-submission peer-review simulation, use the installed `biomed-manuscript-workflow` skill when the request matches its description. Route to the other installed skills according to that workflow; do not run all reviewers on every small edit.

Prioritize original manuscript text, figure panels, supplemental files, and actual raw records. Do not fabricate references, results, p values, or experimental details. Flag unverifiable claims. Preserve original files and generate a separate revision; edits should be minimal, natural, and appropriate for biomedical SCI journals.

The target journal is the one specified for the current manuscript, not automatically Nature. For unpublished manuscripts, follow the relevant authorization and journal AI-use/confidentiality policies.

Respond in Chinese when discussing corrections; manuscript English remains in English. For large audits, return source-location-specific findings and prioritized corrections before rewriting the full manuscript.
